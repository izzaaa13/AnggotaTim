# Daftar Anggota Tim

## Deskripsi Proyek
Daftar Anggota Tim adalah aplikasi web sederhana berbasis React dan Vite yang menampilkan informasi anggota tim dalam bentuk kartu profil. Aplikasi ini dibuat untuk mempelajari pengembangan antarmuka web menggunakan komponen React dan props.

## Daftar Komponen dan Props

### 1. App
Komponen utama yang mengatur tampilan halaman aplikasi dan menampilkan komponen daftar anggota tim.

### 2. AnggotaTim
Komponen untuk menampilkan informasi anggota tim dalam bentuk kartu profil.

Props yang digunakan:
- `nama`: nama anggota tim.
- `nim`: nomor induk mahasiswa.
- `jabatan`: jabatan atau peran anggota tim.
- `aktif`: status keaktifan anggota tim.

## Teknologi yang Digunakan

## Cara Menjalankan Proyek

Pastikan Node.js dan Git sudah terpasang di komputer.

1. Clone repositori:

   ```bash
   git clone https://github.com/izzaaa13/AnggotaTim.git
   ```

2. Masuk ke folder proyek:

   ```bash
   cd AnggotaTim
   ```

3. Instal dependensi:

   ```bash
   npm install
   ```

4. Jalankan aplikasi dalam mode pengembangan:

   ```bash
   npm run dev
   ```

5. Buka alamat lokal yang ditampilkan di terminal, biasanya `http://localhost:5173`.

**Catatan:** Jika proyek aplikasi berada di dalam folder `Anggota-tim`, masuk ke folder tersebut sebelum menjalankan perintah `npm install` dan `npm run dev`.
